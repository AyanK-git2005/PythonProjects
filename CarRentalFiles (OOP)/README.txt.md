This is Command Line Interface (CLI) based online car rental application.

To run the program, execute 'UI_Code.py', ideally using PyCharm or VSCode.

Other Python files are:
- classAccount.py
- classUser.py
- classAdmin.py
- classCar.py
- classReservation.py
- classFile.py
- classExceptions.py
- MiscFunc.py

Only modules from Python's Standard Library were used:
- datetime
- pickle
- os

The software package also includes:
- __pycache__ (folder)
- IDfile.txt
- cars.txt
- reservations.txt
- feedback.txt
- README.txt (this file)
- .pkl files created for storing each object of Car, User, & Reservation type.
- CS-116 CEP Report.pdf
- CS-116 CEP Class Diagram (StarUML file)
- Output1(Admin).txt & Output2(User).txt

Other than 'UI_Code.py', no executable file should be executed manually.

Naming convention detailed in CEP assignment was not used for files' names due to the modular nature of the program.
Using such names would have led to unsatisfactory variable names in the program due to refactoring.
