However it has been made User-Friendly.

POINTS TO BE NOTED:

1. The Code File is named as DBCode.py

2. The Database Files in the Folder are Excel Files.

3. There is one Prime File of each Database File. It contains the name of Primary Key set by the user while creating a Database.
   It's a Text File.

4. There is a file in the Folder named as Masterfile. It contains the Names of all Databases' Files created.
   It's a Text File.

5. There are 4 Text Files in the Folder named as Output1-Output4. These Files contain Four Different Outputs. 
   Except adding Screenshots of the output in the Report, we have made these 4 Files as Output.

6. There is a pdf File in the Folder. This File contains the Report of the Project.
